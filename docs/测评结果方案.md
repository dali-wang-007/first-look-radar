# 初见雷达：测评结果与网站方案

2026-10-31 · 首版设计。用户已授权先设计、继续开发并部署。

## 产品定义

初见雷达——你给陌生人的第一印象，是对用户主动提供的照片中表情、造型、姿态、构图和光线所呈现的视觉印象做趣味解读的网站。面向20～30岁职场女性，提供有细节的正面反馈和容易执行的呈现建议。分析对象是照片，不是人的真实人格、心理状态、能力或陌生人的真实反应。

## 报告结构

| 模块 | 内容规则 | 展示方式 |
|---|---|---|
| 整体印象 | 4～12字视觉风格名称；60～140字说明；必须引用可见细节 | 大标题与摘要 |
| 五维雷达 | 明快感、柔和感、利落感、正式感、松弛感；各1～5档；每轴给出证据 | 雷达图与证据列表，注明非颜值评分、没有优劣排名 |
| 三处亮点 | 每项包括照片中的观察及其视觉效果；不虚构不可见衣服、妆容 | 三张亮点卡 |
| 两条建议 | 指向当前选择的工作头像、客户见面或日常社交场景；均应可自行执行 | 调整动作与预期的画面变化 |
| 分享卡 | 风格标题、雷达、简短评价、趣味解读声明 | 本地导出PNG，默认不含原照片 |

刻度：1=不突出，2=轻微，3=适中，4=较明显，5=突出。刻度表示画面特征强弱，没有综合总分或“越高越好”。模型输出须经结构、长度、刻度范围及禁止内容校验。未通过时明确报错，不用模板充当实际照片分析。

## 输入与异常

| 项目 | 首版规则 |
|---|---|
| 照片 | JPEG/PNG/WebP，原图最大10MB；浏览器重绘为最长1280px的JPEG以去除元数据 |
| 场景 | 工作头像、客户见面、日常社交 |
| 目标 | 自然亲切、清爽利落、柔和松弛；属于用户主动选择，不从面貌推断 |
| 照片质量 | 模型判断是否为单人且面部清晰可见；非人像、多人、遮挡或太暗时请求重传 |
| 同意 | 用户确认有权使用照片，知悉发送给Cloudflare Workers AI做视觉处理 |
| 服务失败 | 显示真实失败和重试入口，不伪造分析；失败不消耗日额度 |

不做明星身份匹配、种族/年龄推断、心理诊断、骨相命运判断、群体百分位、“国际审美”客观排名或外貌缺陷评判。照片中的指令不作为系统指令执行。

## 网站功能与视觉

| 页面 | 功能 |
|---|---|
| 首页 | 产品介绍、明确标注的示例报告、流程说明、隐私说明 |
| 测评 | 拖放/选择照片、预览、场景和目标、明确同意、分析进度、失败重试 |
| 报告 | 雷达、证据、亮点、建议、PNG导出、重新测评 |
| 我的记录 | 登录后跨设备查看文字报告、选择查看、删除单条记录 |
| 账号 | 用户名+密码注册登录、退出、修改密码、删除账号及全部记录 |

视觉采用暖白、酒红、淡粉和少量金色，中文衬线标题搭配清晰正文；移动端优先；键盘可操作、表单有标签、状态可被辅助技术读取。示例与真实报告明确分开。

## 技术与部署取舍

| 方案 | 取舍 | 选择 |
|---|---|---|
| GitHub Pages承载完整应用 | 仅静态托管，不能保护模型密钥或直接承载登录后端；商业SaaS用途受限制 | 仅用于项目介绍与明确标注的示例展示 |
| Cloudflare Workers + D1 + Workers AI | 一处托管静态页面、账号、报告和多模态推理；无需单独传递模型API密钥 | 完整应用 |
| 外部模型API + 外部账号服务 | 可替换模型，但增加密钥、账号和费用配置 | 首版不采用 |

GitHub保存源代码并发布Pages演示。Cloudflare使用独立Worker和D1数据库，避免影响用户已有服务。AI模型使用官方支持视觉输入的`@cf/meta/llama-4-scout-17b-16e-instruct`，实现真实图像分析。首版免费试用，不加入支付。

## 账号、隐私与额度

账号为本站用户名，不冒充已验证邮箱身份。密码至少10位，通过PBKDF2-SHA256、随机盐、100000轮计算存储；会话令牌只保存哈希，HttpOnly/Secure/SameSite Cookie有效7天。支持改密并失效旧会话。首版未接邮箱找回，注册时明确提示。

原照片只在浏览器内存和本次请求中使用，应用不写入数据库、对象存储或日志；Cloudflare作为模型处理方，不能承诺其基础设施绝不保留处理数据。云端保存账号及文字报告，用户可删除报告或整个账号。分享图在浏览器本地生成，默认不含照片；不自动公开报告。

每账号每天最多3次成功测评，整个站点每天最多30次请求进入模型；预留额度采用数据库原子更新，失败释放个人额度，全站模型调用额度不退还，以限制推理开销。注册/登录设IP窗口限流，请求大小、格式、来源和登录状态均在服务端验证。额度可由站点运营者调整。
