## 实施选择与限制

| 事项 | 本次处理 |
|---|---|
| GitHub Pages职责 | 根据GitHub官方托管限制，仅提供示例展示；真实照片与账号均由Cloudflare处理 |
| 发布授权 | GitHub、Cloudflare已有登录状态，未要求用户重复登录；GitHub CLI现有授权不含workflow权限，因此改用gh-pages分支发布，不追加授权 |
| 原照片 | 应用不持久化；模型处理适用Cloudflare条款，不能承诺第三方基础设施绝不留存 |
| 次数 | 每账号每天3次成功分析；全站每天30次模型调用，失败释放个人额度、不退还全站用量；UTC日期重置 |
| 账号恢复 | 用户名与密码登录，首版无邮箱找回；支持改密、删除账号 |
| 内容边界 | 系统提示、结构校验与保守文本规则共同约束；规则不构成完整语义保证，视觉解释仍可能不准确 |
| 效果验证范围 | 已验证真实模型链路与功能，尚未进行目标人群大样本测试或转化率验证 |
| 发布更新 | Cloudflare使用npm run deploy；公开示例使用node scripts/deploy-pages.mjs；无自动CI发布依赖 |
